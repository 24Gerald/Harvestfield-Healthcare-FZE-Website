Partner and supporter logos for the "Local manufacturing" section.
Drop files here and they are picked up automatically (no code change):

  pvac.png        (or .svg / .jpg / .webp)  — Presidential Initiative on Healthcare Value Chain
  oguninvest.png  (or .svg / .jpg / .webp)  — OgunInvest
  harvestfield-industries.png            — Harvestfield Industries (collaboration section, light background)
  harvestfield-industries-white.png      — white version for the footer (dark background); falls back to the plain file
  iso.png / who.png / nafdac.png         — certification marks for the "Certified by" section (in-house stand-ins until the official files arrive)

The file name must contain the partner's `logo` key from src/data/content.js
(localCapability.supporters). Until a file exists, the partner's name is shown
as a wordmark in its place.
