Portraits for the "Management" section.
Drop files here and they are picked up automatically (no code change):

  chairman.jpg            (or .png / .webp)  — Martins A. Awofisayo, Chairman
  managing-director.jpg   (or .png / .webp)  — Isaac Awofisayo, Managing Director

The file name must contain the person's `photo` key from src/data/content.js
(management.people). Portraits are shown at a 4:5 ratio, cropped from the top
(head and shoulders), never stretched. Until a file exists the person's
initials are shown in the frame.
