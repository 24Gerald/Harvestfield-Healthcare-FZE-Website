Photos for the "Certified by" section (Quality built into every stage).
Drop files here and they are picked up automatically (no code change):

  iso-photo.jpg     — HHC QC / production inspection
  who-photo.jpg     — LLIN laboratory / testing scene
  nafdac-photo.jpg  — HHC factory / production line

(.jpg, .jpeg, .png or .webp; landscape, about 1200×800 or larger.)
The file name must contain the item's `key` from src/data/content.js (certified.items)
followed by "-photo". Until a file exists a labelled placeholder is shown.

The three certification logos go in src/assets/partners/ as iso.png, who.png and
nafdac.png (see the README there).
